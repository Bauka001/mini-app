# Көзқырағы — Focus Game

Қысқа мерзімді көру жадысын және зейінді жаттықтыратын шағын ойын. Telegram Mini App ретінде немесе кәдімгі браузерде ашылады.

## Жергілікті сынау

Жай ғана `index.html` файлын браузерде ашыңыз — ойын жұмыс істейді.

Немесе жергілікті сервер арқылы:

```bash
# Python бар болса
python -m http.server 8000
# Содан кейін: http://localhost:8000
```

## Telegram Mini App ретінде қосу

### 1-қадам. Файлдарды хостингке қою

Ойынды қайсыбір HTTPS-хостингке жүктеу керек (Telegram HTTP-ті қабылдамайды). Қарапайым нұсқалар:

- **GitHub Pages** (тегін): жаңа репозиторий құрып, `index.html`-ды push етіп, Settings → Pages-тен іске қосыңыз. URL: `https://username.github.io/reponame/`
- **Netlify** (тегін): папканы netlify.com-ға тартып-тастасаңыз, бірнеше секундта URL береді.
- **Vercel** (тегін): `vercel` CLI немесе web-интерфейс арқылы deploy.
- **Cloudflare Pages** (тегін).

### 2-қадам. BotFather арқылы бот жасау

1. Telegram-да `@BotFather`-ге `/newbot` жазыңыз.
2. Бот атын беріңіз (мысалы, "Көзқырағы").
3. Username беріңіз (мысалы, `kozkyragy_bot`).
4. BotFather сізге токен береді — сақтап қойыңыз.

### 3-қадам. Mini App-ты жалғау

BotFather-ге қайтадан барыңыз:

1. `/mybots` → өз ботыңызды таңдаңыз
2. **Bot Settings** → **Menu Button** → **Configure menu button**
3. Атауын енгізіңіз (мысалы, "▶ Ойнау")
4. Жоғарыдағы hosting URL-ын жіберіңіз (мысалы, `https://username.github.io/kozkyragy/`)

Болды. Енді ботыңызды ашқанда төменде "Ойнау" түймесі шығады, оны басқанда ойын ашылады.

### Балама: /setmenubutton емес, Direct Link

1. `/mybots` → бот → **Bot Settings** → **Configure Mini App**
2. URL-ды жіберіңіз.
3. Ботқа сілтеме `https://t.me/kozkyragy_bot/app` түрінде болады.

## Ойын механикасы

- **12 деңгей**, әр деңгейде қиындық артады (объект саны көбейеді, уақыт азаяды).
- **3 сұрақ типі**:
  - *Presence* — қайсысы көріністе болды
  - *Absence* — қайсысы болған жоқ
  - *Count* — қанша [X] болды
- **Жұлдыз жүйесі**: 3 жұлдыз (бәрі дұрыс) / 2 / 1 / 0.
- **Прогресс** `localStorage`-та сақталады — қайта ашсаңыз жоғалмайды.
- **Telegram Haptic Feedback** қосылған (телефонда дірілдейді).

## Дамыту жоспары (келесі қадамдар)

1. 15-20 досқа жіберіп, retention-ды өлшеу.
2. Жаңа сұрақ типтерін қосу — *location* (қай жерде тұрды), *order* (не қайсыдан кейін).
3. Күнделікті челлендж (бір фиксті scene, күніне бір рет).
4. Рейтинг (leaderboard) — backend керек (Firebase/Supabase ең оңай).
5. Косметика — аватар, ою рамкалары (Telegram Stars арқылы).
6. Emoji орнына нақты суреттер — қазақ даласы стилінде.

## Техникалық ескертулер

- Mobile-first дизайн, iPhone/Android-та жақсы істейді.
- Ені 500px-ға шектелген (десктопта ортада тұрады).
- `localStorage` қолданылады — жеке қолданушы үшін жеке прогресс.
- Telegram WebApp SDK жоқ болса да істейді (fallback).

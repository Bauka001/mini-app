## Тетрис ойынын батырмаларын жақсарту

### 1. Hard Drop батырмасын қосу
- Фигураны бірден түсіру үшін жаңа батырма қосу
- Space немесе басқа батырмасын қолдану

### 2. Батырмаларды қайта орналастыру
- 4 батырма орнына 5 батырма орналастыру
- ArrowLeft (сол) → Жаңа орны
- Hard Drop (бас) → RotateCw (айналдыру) орнына
- RotateCw (айналдыру) → ArrowRight (оң) орнына
- ArrowRight (оң) → Жаңа орны
- ArrowDown (түсу) → Жаңа орны

### 3. Клавиатура басқаруын қосу
- Arrow Left → солға жылжыту
- Arrow Right → оңға жылжыту
- Arrow Up → айналдыру
- Arrow Down → түсу
- Space → hard drop

### 4. Батырмаларды заманауи стильмен жақсарту
- Анимациялар мен әсерлерді қосу
- Gradient түстерді қолдану
- Hover/Active әсерлерді қосу
